# Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application that allows users to browse and purchase houseplants conveniently. The application provides plant details, including images, names, descriptions, and prices.

## Features
- Browse houseplants grouped into different categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities in the cart.
- Remove plants from the cart.
- View the total price of cart items.
- Navigate between Home, Plants, and Cart pages.
- Display the total number of items in the shopping cart.
- Show a checkout message indicating that checkout is coming soon.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Redux Toolkit

## Project Name
Paradise Nursery Shopping Application

## Purpose
The purpose of this project is to develop an interactive e-commerce website for an online plant nursery using React and Redux for state management.
